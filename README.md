# HERS — Community Selection Platform

Plateforme de travail pour prioriser les communautés à consulter.

## Installation
```bash
npm install
npm run dev
```

## Fonctionnalités
- Carte interactive des 1 388 communautés.
- Classement recalculé dans le navigateur.
- Sélection dynamique par pays et nombre de communautés.
- Filtres : pays, région, langue, bureau, recherche, sélection.
- Fiche détaillée avec décomposition du score.
- Pondération modifiable pour tester des scénarios.
- Contrôle linguistique et indicateur de couverture des données.

## V1
Sénégal : 642 consultations (584 communautés projet à terme).
Gambie : 161 consultations (146 communautés projet à terme).
Score : Population 35 + Distance 25 + Densité 10 + Récence PRCC 20 + Durée PRCC 10.
La langue ne donne pas de points directs.
